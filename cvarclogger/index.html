Key Features

  • Log amateur radio contacts (QSOs) with detailed information
  • Track DXCC, WAS, SOTA, POTA, and SKCC awards
  • Radio CAT control via Hamlib (supports 300+ radios)
  • Automatic callsign lookups from Callook, QRZ, and QRZCQ
  • ADIF import/export for log exchange
  • SQLite database (fully portable)
  • Multi-contest scoring (Field Day, CQ WW, ARRL DX, NAQP, SKCC, and more)
  • Windows 10/11 (64-bit) support
  • Live frequency and mode display from radio
  • Grid square and ARRL section resolution
  • Multi-database support for different logs
  • Integrated help system with searchable manual
