CvarcCellLog Changelog
======================
One entry per published version. Add a new entry here every time ApplicationDisplayVersion (in
CvarcCellLog.csproj) is bumped for a build meant to reach the user -- before publishing.

Versions before 1.01 predate this changelog and are not documented here.

1.04
----
- Edit/New QSO: My SOTA/SOTA and My POTA/POTA fields are now paired on the same line.
- Added max character limits to several fields to match real-world formats: Callsign 10, Frequency 6,
  RST/S and RST/R 4, Grid Square 6, State 2, ARRL Section 4, CQ Zone 1, ITU Zone 1, UTC Offset 3.
- Home page and the startup screen now show the app's version number.
- Station Profiles page reorganized: Callsign/Operator Callsign, Grid Square/State, and UTC Offset/DST
  are now paired on the same line to shorten the form.
- Station Profiles and Edit QSO: "Observes Daylight Saving Time" shortened to "DST".
- Edit/New QSO: CQ Zone and ITU Zone, and Grid Square and State, are now paired on the same line.
- Edit/New QSO: Band, Mode, and Sub-Mode ("SubM") are now on one line; Digital Voice mode shows as "DV"
  in the picker (still saved/exported as the correct ADIF "DIGITALVOICE" value).
- New QSO: selecting a Station Profile now shows that profile's Operator Callsign, Op, Grid Square,
  State, County, QTH, UTC Offset, and DST right on the form, instead of only the callsign in the picker.

1.03
----
- Edit/New QSO: RST Sent/Rcvd relabeled "RST/S"/"RST/R" and moved onto one row; added a TXp (TX Power,
  watts) field next to Frequency; added a Time Off (UTC) field for logging when a contact ended. All
  three are also available as QSO Log columns.
- Fixed Edit QSO's Lookup button not refreshing State and other fields when they were already filled in
  -- a successful lookup now always overwrites, matching what you'd expect from a re-lookup.
- ADIF import now drops non-English (non-ASCII) characters from imported text fields (Name, Comment,
  City, etc.) instead of importing mojibake for names that used non-Latin encodings.
- Settings: Show/Hide password now correctly reveals the saved QRZ/QRZCQ password after it's been saved
  (previously the field stayed blank after Save, so Show had nothing to display).

1.02
----
- QSO Log: column headers are now tappable to sort the log by that column -- tap again to reverse
  direction. The currently-sorted column shows an arrow (up/down) in its header.

1.01
----
- Settings: added a Show/Hide toggle button next to the QRZ.com and QRZCQ.com password fields, so you
  can verify what you typed before saving.
- Edit QSO: added a Lookup button (previously only on the New QSO / entry page), so an already-logged
  contact's blank fields can be filled in later without re-entering it.
- Fixed a bug where UTC Offset, Frequency, CQ Zone, and ITU Zone never showed any on-screen keyboard --
  Keyboard="Numeric" itself was suppressing the IME on-device. All four now use the default keyboard,
  which shows reliably.
- QSO Log redesigned: one line per record instead of two, a fixed header row that doesn't scroll with
  the list, and a new Columns screen (QSO Log's overflow menu) to choose which fields show and reorder
  them with Up/Down buttons. Column choice is saved and persists between sessions.
